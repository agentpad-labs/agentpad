step 01

Create

An Agent ID holder pays 0.002 BNB. The token deploys with a fixed supply and the whole supply goes into its curve, in one transaction.

step 02

Agent window

For 30 minutes only wallets holding an Agent ID can buy. After that the curve opens to everyone.

step 03

Trade

Buys and sells run against virtual reserves. There is no pool to snipe, and selling back always works.

step 04

Graduate

At 8 BNB the curve closes and pairs on PancakeSwap. The LP tokens go to a locker with no withdraw path.
